# Product direction

Agent Tasks is the owner's on-demand view of agent development. One agreed goal and flat outcomes per repository are compared with committed changes, current target content, drafts and relevant runtime observations. Several agents may contribute; outcomes, not agents or commits, are counted.

Implementing agents do not maintain reports, complete task records or follow tracking ceremonies. Planning saves intent once; scope changes follow owner discussion. The compact Russian report is an estimate with explicit uncertainty. It is not automated acceptance, task enforcement, a runtime controller or a substitute for tests.

No work hierarchy, project registration, extra documentation repository, database, watcher or continuous model calls belongs in this version. Installation/publication and managed role activation remain explicit operational steps.

When Bridge is configured, one status request delivers the final short report as a message, requiring no follow-up tool call from the implementing agent. The plan retains the creating agent's contact from host metadata for later communication. Delivery is not continuous monitoring, and an address is not proof that its agent is still reachable.
